# HAR7

HAR7 is an IPTV player for Windows: live TV with a TV guide, movies and series, in English and Arabic.

## Download

Get the newest installer from the [`releases`](releases) folder (the highest version number), then run it.

Windows may show **"Windows protected your PC"** the first time. Click **More info → Run anyway**.

HAR7 has no channels of its own: sign in with your own IPTV account (Xtream Codes, M3U link or M3U file).

## Updates

HAR7 checks for a new version each time it opens and offers an **Update now** button. Nothing to download by hand after the first install.

---

`latest.json` is what HAR7 reads to find the newest version. Installers are signed; HAR7 only installs updates carrying HAR7's signature.
